# HR Employee Attrition Analysis
End-to-end HR analytics project analyzing employee attrition using Python (data analysis) and Power BI (Interactive dashboard) to identify key drivers of employee turnover.
## Overview
This project analyzes employee attrition using both Python and Power BI to identify key factors influencing employee turnover.
## Tools Used
- Python (Pandas, Data Cleaning, Exploratory Data Analysis)
- Power BI (Interactive Dashboard & Data Visualization)
## Key Insights
- Employees in Sales and Technical departments show the highest attrition rates
- Lower salary levels are strongly associated with higher attrition
- Employee satisfaction is a major factor affecting retention
- Most employees leave around their third year in the company
## Files
- Python notebook for data analysis
- Power BI dashboard (.pbix)
- Visual reports (.PDF)
- Dataset (.XLS)
## Goal
To understand the main drivers of employee attrition and provide actionable insights for HR decision-making.
